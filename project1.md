2.1. Перемещение по файловой системе

2.1.1 Авторизуйтесь в системе в текстовом режиме, либо в графическом
режиме. Если вы работаете в графическом режиме, запустите программу
эмулятора терминала.
2.1.2 Выведите имя текущего пользователя, установите, в каком каталоге вы
сейчас находитесь.
 whoami && pwd
2.1.3 Перейдите в корневой каталог. Попробуйте перейти в каталог уровня
выше.
cd / && pwd && cd .. && pwd
2.1.4 Выведите список файлов текущего каталога.
ls
2.1.5 Выведите список файлов каталога /etc.
ls /etc
2.1.6 Перейдите в домашний каталог текущего пользователя.
cd
2.1.7 Выведите список файлов и каталогов текущего каталога.
ls
2.1.8 Выведите список файлов и каталогов (включая скрытые) с информацией
о владельце и правах доступа.
ls -la

2.2. Работа с файловой системой

2.2.1 В домашнем каталоге текущего пользователя создайте подкаталог fruits.
mkdir fruits
2.2.2 Перейдите в корневой каталог. Из корневого каталога создайте в
домашнем каталоге подкаталог animals.
cd / && mkdir ~/animals
2.2.3 В подкаталоге корневого каталога, предназначенного для хранения
временных файлов, создайте пустой файл temp.
touch /tmp/temp
2.2.4 Используя команду echo и перенаправление вывода запишите в файл temp
строку «Hello». Второй такой командой допишите строку «world». Откройте
файл при помощи текстового редактора nano, добавьте в конец три знака «!»,
сохраните запись и выполните выход из редактора.
echo "Hello" > temp && echo "world" >>temp

2.2.5 Перейдите в каталог fruits и создайте в нем пустые файлы apple, banana,
pineaple, lion (используйте соединение команд при помощи &&).
cd ~/fruits && touch apple banana pineaple lion
2.2.6 Находясь в каталоге fruits, создайте в каталоге animals пустые файлы
cat.txt, dog.txt, elephant.txt одной командой.
touch ~/animals/cat.txt ~/animals/dog.txt ~/animals/elephant.txt
2.2.7 Выведите все файлы каталога fruits, имя которых начинается с буквы a.
ls a*
2.2.8 Выведите все файлы каталога fruits, имя которых заканчивается буквой e.
ls *e
2.2.9 Выведите все файлы каталога fruits, имя которых содержит буквы a и n.
ls *a*n*
2.2.10 Скопируйте файл с учетными записями пользователей системы в
домашний каталог текущего пользователя. Выведите на экран количество
строк в этом файле. В домашнем каталоге создайте символьную ссылку на этот
файл. Определите номер inode этой ссылки.
cp /etc/passwd ~/passwd && wc -l < ~/passwd
cd
ln -s ~/passwd ~/link && ls -i ~/link
2.2.11 Выведите содержимое файла /etc/issue на экран.
cat /etc/issue
2.2.12 Скопируйте файл /etc/issue в файл apple с заменой содержимого,
выполните проверку.
cp /etc/issue ~/fruits/apple && cat ~/fruits/apple
2.2.13 Переместите файл lion в каталог animals.
mv ~/fruits/lion ~/animals/
2.2.14 Исправьте опечатку в имени файла pineaple.
 mv ~/fruits/pineaple ~/fruits/pineapple && ls ~/fruits
2.2.15 В домашнем каталоге создайте жесткую ссылку на файл истории команд
командной оболочки. Выведите информацию о количестве жестких ссылок на
этот файл.
ln ~/.bash_history ~/history_link && ls -l ~/.bash_history ~/history_link
2.2.16 Удалите каталог fruits.
rm -r ~/fruits
2.2.17 Выведите на экран содержимое файла лога загрузки операционной
системы.
cat /var/log/boot.log


2.3. Механизм конвейеров
2.3.1 Выведите на экран отсортированный по алфавиту список пользователей
операционной системы.
cut -d: -f1 /etc/passwd | sort
2.3.2 Выведите на экран число пользователей, у которых командной оболочкой
является bash.
grep -c '/bin/bash$' /etc/passwd
2.3.3 Выведите на экран только имена пользователей, использующих
командную оболочку bash, отсортировав их по алфавиту в обратном порядке.
grep '/bin/bash$' /etc/passwd | cut -d: -f1 | sort -r
2.3.4 Выведите на экран имена пользователей и используемую ими командную
оболочку (в две колонки).
cut -d: -f1,7 /etc/passwd | column -t -s:


2.4 Получение прав суперпользователя
2.4.1 Выведите на экран содержимое файла с паролями пользователей,
выполняя команду от имени текущего пользователя.
cat /etc/shadow
2.4.2 Выведите список групп текущего пользователя на экран. Установите,
входит ли ваш пользователь в группу администраторов? Если нет, завершите
сеанс текущего пользователя и авторизуйтесь как root. Включите пользователя
в группу администраторов командой usermod.
groups
2.4.3 От имени суперпользователя (sudo <>) выполните команду из п. 2.4.1.
sudo cat /etc/shadow
2.4.4 Выведите список
администраторов.
всех
пользователей,
входящих
в
группу
getent group sudo
2.4.5 Обновите список доступных для установки пакетов, выполните
установку пакета build-essential. Проверьте версии установленных
компиляторов и средств автоматизации сборки.
sudo apt update
sudo apt install build-essential
gcc --version && g++ --version && make --version


2.5 Поиск файлов и каталогов
2.5.1 Изучите доступные опции утилиты find.
find --help
2.5.2 Найдите все файлы и каталоги, имя которых содержит подстроку pass с
учётом регистра.
find ~ -name "*pass*"
2.5.3 Найдите все файлы и каталоги, имя которых содержит подстроку pass без
учёта регистра.
 find ~ -iname "*pass*"
2.5.4 Найдите все файлы и каталоги, имя которых содержит подстроку pass с
учётом регистра. Начните поиск с / и ограничьте глубину одним уровнем.
find / -maxdepth 1 -name "*pass*"
2.5.5 Найдите все файлы и каталоги, имена которых оканчиваются на .bin.
Выполните поиск в каталоге /home и всех его подкаталогах.
find /home -name "*.bin"
2.5.6 Найдите все обычные файлы и только их, имена которых оканчиваются
на .bak, и удалите их.
find ~ -type f -name "*.bak"
find ~ -type f -name "*.bak" -delete
2.5.7 Найдите все обычные файлы и только их, имена которых оканчиваются
на .txt или .sh.
find / -type f -name "*.txt"
find / -type f -name "*.sh"
2.5.8 Найдите все обычные файлы и только их в текущем каталоге и всех его
подкаталогах. Для каждого файла выведите только следующие сведения: имя
файла без пути, имя владельца, имя группы владельца, количество жёстких
ссылок и размер в байтах.
find . -type f -printf "%f %u %g %n %s\n"
2.5.9 Найдите все пустые каталоги внутри текущего каталога, включая
вложенные. Сам текущий каталог в результат не включайте.
find . -mindepth 1 -type d -empty
2.5.10 Найдите и удалите все пустые каталоги внутри текущего каталога,
включая вложенные. Сам текущий каталог сохраните.
find . -mindepth 1 -type d -empty
2.5.11 Найдите и удалите все пустые обычные файлы и только их. Пустым
считайте файл размером 0 байт.
find . -mindepth 1 -type f -empty
rm ~/animals/cat.txt ~/animals/dog.txt ~/animals/lion ~/animals/elephant.txt
2.5.12 Найдите все обычные файлы и только их в текущем каталоге и всех
его подкаталогах, у которых количество жёстких ссылок больше одной.
find . -type f -links +1
2.5.13 Найдите все файлы и каталоги в /etc и его подкаталогах, не
принадлежащие пользователю root. 
find /etc -not -user root
2.5.14 Найдите все обычные файлы и только их, имена которых не
оканчиваются на .sh. Файлы без расширения также должны попадать в
результат.
find . -type f -not -name "*.sh"
2.5.15 Найдите все обычные файлы и только их, у которых количество
жёстких ссылок больше двух.
find . -type f -links +2
2.5.16 Найдите все обычные файлы и только их в /usr/bin и его подкаталогах,
сохранённая метка последнего доступа к которым (atime) указывает на время
более 90 суток назад.
find /usr/bin -type f -atime +90
2.5.17 Найдите все обычные файлы и только их в каталогах /usr/bin и
/usr/share, включая их подкаталоги, содержимое которых изменялось в
течение последних 10 суток. Используйте время изменения содержимого
(mtime).
find /usr/bin /usr/share -type f -mtime -10
2.5.18 Найдите и удалите все обычные файлы и только их в /tmp и его
подкаталогах, последнее изменение содержимого которых произошло более
14 суток назад. Используйте время изменения содержимого (mtime).
find /tmp -type f -mtime +14
find /tmp -type f -mtime +14 -delete 2>/dev/null
